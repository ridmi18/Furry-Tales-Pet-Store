# 🐾 Furry Tales - Pet Store

Furry Tales is a responsive pet store website developed using HTML, CSS, and JavaScript. It provides a simple and user-friendly interface for exploring pets and pet-related services.

## Features

- Responsive and user-friendly design
- Pet listings with images and details
- Pet filtering by category and age
- Pet services information
- About Us and Contact pages
- Easy navigation

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/ridmi18/Furry-Tales-Pet-Store.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.
